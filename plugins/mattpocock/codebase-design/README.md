# codebase-design

Terms and checks for module design: depth, interface size, seams, testability. Includes the deepening and design-it-twice procedures.

## Install

```
/plugin marketplace add ykurt52/skill-sets
/plugin install codebase-design@skill-sets
```

## Run

```
/codebase-design:codebase-design where should the seam be between the protocol stack and the HAL
```

## Output

Design discussion and options in the chat.

```

```
