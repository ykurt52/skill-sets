# writing-for-agents

Guidance for writing skills and agent instruction files: what to keep in the always-loaded part, what to move behind a pointer, how to word triggers, and how to prune.

## Install

```
/plugin marketplace add ykurt52/skill-sets
/plugin install writing-for-agents@skill-sets
```

## Run

```
/writing-for-agents:writing-for-agents review this SKILL.md
```

## Output

Edits or advice in the chat. The agent also loads it on its own when you edit a skill or CLAUDE.md.

## Layout

```
skills/writing-for-agents/SKILL-MECHANICS.md
skills/writing-for-agents/SKILL.md
```
