# wait-what

Use it right after an answer that was too dense or used terms you do not know. The agent restates the same point simply, using the terms the project already uses.

## Install

```
/plugin marketplace add ykurt52/skill-sets
/plugin install wait-what@skill-sets
```

## Run

```
/wait-what:wait-what
```

## Output

A short restatement in the chat, in Simplified Technical English and with the terms from the repo's `GLOSSARY.md` if it has one.

## Layout

```
skills/wait-what/SKILL.md
```
